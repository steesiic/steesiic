## 🚀 Featured Project

### [TeamUP-Azure](https://github.com/steesiic/TeamUP-Azure)

**Status: Work in Progress** 🚧

A full-stack sports scheduling and facility booking application built with React and ASP.NET Core. The current version focuses on core functionality, with additional features planned for future development.

- Backend deployment to Microsoft Azure
- Frontend hosting using Azure Storage
- Automated CI/CD with GitHub Actions
- SQLite database integration
- **Planned:** Real-time chat, notifications, and interactive maps
